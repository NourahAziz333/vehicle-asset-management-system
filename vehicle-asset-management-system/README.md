# Company Vehicle Asset Management System (Part I)

## Overview
This is the **frontend (React.js)** for a Vehicle Asset Management System. It manages **Three asset categories** (company transportation vehicles) and supports **CRUD** operations:

- Add vehicle asset
- View vehicle asset list
- Update vehicle asset
- Delete vehicle asset

Data is stored in the browser using **Local Storage** (no backend in Part I).
